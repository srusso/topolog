# Notes for agents working on this codebase

Topolog is a small libgdx application that renders topology (covering spaces, fundamental groups, surfaces) as
interactive 3D worlds. Read these notes before you start; they are what we learned the hard way.

- [working-agreements.md](working-agreements.md): how we like to work (commits, pushing, scope, honesty)
- [build-and-verify.md](build-and-verify.md): building, and checking geometry without a screen
- [libgdx-lessons.md](libgdx-lessons.md): libgdx and graphics pitfalls we ran into
- [topology-and-meshes.md](topology-and-meshes.md): how the surfaces and folds are built, and how we checked them
- [adding-a-world.md](adding-a-world.md): the checklist for a new world

Keep these files up to date. If you learn something that would have saved you time, add it here.
